## X-BQSR - Holistic Acceleration of Base Quality Recalibration for Scalable Genomic Analysis

### Overview

This is a GPU-accelerated implementation of the GATK Base Quality Score Recalibration (BQSR) workflow using SYCL for heterogeneous computing. The tool analyzes quality score patterns in aligned DNA sequences and recalibrates base quality scores to improve accuracy for variant calling and other downstream analyses.

BQSR operates in two stages:
1. **Recalibrate** - Analyzes aligned reads and generates recalibration tables based on quality score correlations with different covariates (read group, position in cycle, context)
2. **Apply** - Uses the recalibration tables to adjust quality scores in the input BAM file

### Supported Formats

- **Input/Output**: BAM files (aligned DNA sequences)
- **Reference**: FASTA format genome reference
- **Known Variants**: VCF format files for calibration

### Features

- Multi-GPU acceleration using SYCL for parallel processing
- Covariates: read group, base quality score, cycle position, and dinucleotide context

### Usage

#### Display help message
```
./bqsr -h
./bqsr --help
./bqsr <command> -h          # Command-specific help
```

#### Generate recalibration tables (Recalibrate command)
```
./bqsr recalibrate --bam-in input.bam \
                   --recal-out recal.txt \
                   --ref reference.fasta \
                   --known-sites known_variants.vcf
```

#### Apply recalibration (Apply command)
```
./bqsr apply --bam-in input.bam \
             --bam-out output.bam \
             --recal recal.txt
```

### NVIDIA Docker Image

Build the CUDA/AdaptiveCpp image:

```
docker build -f Dockerfile.cuda -t x-bqsr:cuda-sm89 --build-arg CUDA_ARCH=sm_89 .
```

Run with NVIDIA GPU passthrough:

```
docker run --rm --gpus all -v /path/to/data:/data x-bqsr:cuda-sm89 \
  recalibrate --bam-in /data/input.bam \
              --recal-out /data/recal.txt \
              --ref /data/reference.fasta \
              --known-sites /data/known_variants.vcf
```

```
docker run --rm --gpus all -v /path/to/data:/data x-bqsr:cuda-sm89 \
  apply --bam-in /data/input.bam \
        --bam-out /data/output.bam \
        --recal /data/recal.txt
```

The host must have working NVIDIA drivers and NVIDIA Container Toolkit support.

### Command-line Arguments

**Global Options:**
- `--help, -h` - Display help message
- `<command>` - Positional argument specifying which operation to perform

**Recalibrate Command:**

Required options:
- `--bam-in <file>` - Input BAM file with aligned reads
- `--recal-out <file>` - Output file for recalibration tables
- `--ref <file>` - Reference genome in FASTA format
- `--known-sites <file>` - Known variant sites VCF file (comma-delimited list supported for multiple files)

Optional options:
- `--gpus <num|all>` - Number of GPUs to use (default: 1). Use `all` to utilize all available GPUs.

**Apply Command:**

Required options:
- `--bam-in <file>` - Input BAM file with original quality scores
- `--bam-out <file>` - Output BAM file with recalibrated quality scores
- `--recal <file>` - Recalibration table file (generated by recalibrate command)

Optional options:
- `--gpus <num|all>` - Number of GPUs to use (default: 1). Use `all` to utilize all available GPUs.
